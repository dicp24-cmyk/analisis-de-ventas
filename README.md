# Análisis de ventas

Práctica de análisis de datos empresariales con Python (pandas) y Excel.

## Descripción
Análisis de una base de 150 ventas ficticias (enero 2025 a octubre 2026) de una empresa que vende productos de tecnología, oficina y software en 4 regiones. El objetivo es practicar limpieza de datos, cálculo de indicadores y conclusiones para la gerencia.

## Contenido
- `practica_analisis_datos_empresariales.xlsx`: datos, ejercicios y soluciones
- `notebooks/`: análisis en Python (próximamente)

## Indicadores analizados
- Ingreso total y margen %
- Ventas por región, producto, vendedor y categoría
- Crecimiento año contra año
- Ventas con margen negativo

## Herramientas
- Python 3
- pandas
- openpyxl

## Cómo usarlo
1. Descarga el archivo Excel.
2. Instala las librerías: `pip install pandas openpyxl`
3. Carga los datos con `pd.read_excel("practica_analisis_datos_empresariales.xlsx", sheet_name="Ventas")`
